## 一、总览（30 秒 · 项目定位）

| 维度 | 一句话 |
|---|---|
| 是什么 | **科研级 AI 教学闭环系统**：教师备课 → 学生分步练习 → 智能学情反馈 |
| 解决什么 | 老师"管太多、跟太累"、学生"练不对、没人陪"、管理员"看不到全貌" |
| 跑在哪 | 单二进制 Go 后端（18080）+ Next.js 16 静态前端（3000）+ SQLite 单文件 |
| 核心差异 | **信任分门控辅导**（不是直接给答案）+ **屏幕感知**（教练"看见"你）+ **RAG 检索**（结合课程资料） |

> **演讲节奏**：20 秒讲完上面表格；点 3 次鼠标切换 3 个端作为视觉钩子。

## 二、5 分钟分镜（4 镜头 + 1 收尾）

### 🎬 镜头 1 ｜ 0:00 – 1:30 ｜ **超管总览：平台已就绪**

**操作**（45 秒）
1. Chrome 打开 `http://127.0.0.1:3000/?demo=admin&hidechrome=1`
2. 鼠标在 "平台已就绪" 标题上**悬停 2 秒**（让观众看到 KPI 数字）
3. 滚到底栏「人员名单 → 账号管理」→ 展示 5 个账号

**旁白**（30 秒）
> "这是云元平台的超管视角。LLM 已就绪、16 份教案资料、2 个学生、1 个班级在用。
> 左侧 KPI 卡是平台关键指标——不是堆数据墙，只放最该看的两个：教案数和用户数。
> 切到'账号管理'，admin 可以一键停用任意教师账号、查看用户名、看到角色徽章和班级归属。
> 这就是 SaaS 平台最基础的治理面：人员、资料、任务、配置都在这里。"

**视觉焦点**：KPI 大数字、角色徽章颜色（admin-靛 / teacher-绿 / student-灰）

---

### 🎬 镜头 2 ｜ 1:30 – 2:45 ｜ **教师导入教案：Agent 智能解析**

**操作**（45 秒）
1. 切到 `?demo=teacher&hidechrome=1`
2. 底栏「资料」→ 弹出导入面板
3. 拖一个 PDF（数据库原理课件）进上传区
4. **慢镜头**：看 Agent 报告卡出现——"✅ 教案 1 · 接受 7 个概念 · 4 个学习难点"

**旁白**（30 秒）
> "现在切到教师工作台。点'资料'——上传一个数据库原理的课件 PDF。
> 注意这里没有 OCR、没有手工打标签。Agent 会**自动识别意图**——是教案还是学生名单还是噪声。
> 报告卡告诉你：它接受了 7 个核心概念、识别了 4 个常见难点。
> 这就是我们的 RAG 检索基础——所有学生提问都会先在这 7 个概念里查。"

**视觉焦点**：上传后 1.5 秒内报告卡自动出现；显示"概念 / 难点 / 学习路径"三栏

---

### 🎬 镜头 3 ｜ 2:45 – 3:45 ｜ **教师智能出题：分步作业卡**

**操作**（35 秒）
1. 在教师端对话输入框打："根据关系模型这一节出一道分步作业"
2. 慢镜头：Agent 返回**步骤卡**（步骤 1/2/3 + 引用资料）
3. 点"发布" → 跳到任务列表

**旁白**（25 秒）
> "教师不用手写教案了。在对话里说一句'给我出个分步作业'——Agent 会结合刚才的 RAG 检索结果，给出 2-3 步的引导式问题，每步都标了引用了哪份资料。
> 老师只需要确认、调整、发布。学生端立刻能看到任务。
> 整条路径：**导入 → 检索 → 出题 → 发布**，全在 AI 工作台里。"

**视觉焦点**：卡片上 "📎 结合了你当前页面与资料：《关系模型基础》" 这一行——证明 RAG 真在用

---

### 🎬 镜头 4 ｜ 3:45 – 4:45 ｜ **学生练习流：信任分门控 + 屏幕感知**

**操作**（40 秒）
1. 切到 `?demo=student&hidechrome=1`
2. 底栏「练习」→ 进入答题台
3. 学生输入一段**半对半错**的答案（提前用 ?demo=student 注入）
4. **关键镜头**：教练浮层弹起——**不直接给答案**，而是反问
5. 完成后底部"做得好"+ confetti + 信任分 +1

**旁白**（25 秒）
> "最后看学生端。点'练习'进入答题台。学生提交答案后，**教练不是直接判对错**——
> 我们的'信任分门控'机制：低信任分的学生，教练只**追问**'你能再举一个外键例子吗'，不直接给答案。
> 高信任分才解锁解释。这就是项目核心差异：**教练不抢学生的思考**。
> 底部那个 confetti 是完成庆祝——`StarBurst` + 信任分 +1。整套动效是 React Bits 真品。"

**视觉焦点**：
- 教练气泡的**反问**语气（"你觉得外键参照完整性是……？"）
- 完成时 confetti + 信任分增加
- 整页移动端 1 列布局（< 640px 单列堆叠）

## 三、录屏 Tips

| 项 | 建议 |
|---|---|
| 录屏软件 | **OBS Studio 30.0+**（开源免费，1920×1080 @ 25fps，CRF 18） |
| 麦克风 | **入耳式 + 桌面麦** 双备份；测试 `-6dB` 不破音 |
| 录屏窗口 | Chrome 无痕模式（避免扩展/书签栏入镜） |
| Chrome 主题 | 浅色（项目设计稿基于浅色 token） |
| 录后剪辑 | DaVinci Resolve / CapCut；3 段 5 分钟 + 1 段 30 秒片头 + 1 段 15 秒片尾 |
| 字幕 | 自动生成 + 人工校对（"信任分门控"等术语不简写） |
| BGM | 选 1 首安静电子（不超过 -20dB） |

## 四、踩坑清单（录前必看）

| 坑 | 怎么避 |
|---|---|
| 后端 30 分钟 timeout 自动退出 | 录前**重启一次**；录屏时长 < 5 分钟够用 |
| 浏览器 session 过期（30 分钟） | 录前清 localStorage，用 `?demo=` 跳过登录 |
| 引导横幅遮挡 | 用 `?hidechrome=1` 隐藏 |
| 浮窗"教学 Agent"遮挡关键区域 | 同上 |
| LLM 没配 key → 走规则降级，看不到 streaming | 提前填 DeepSeek key 到 .env（`YUNQUE_BASE_URL` + `YUNQUE_API_KEY`） |
| 中文显示成"?" | 浏览器装「Noto Sans CJK SC」字体；或 PowerShell 控制台 + 字体 ≠ 浏览器渲染 |
