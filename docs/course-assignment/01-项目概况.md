> **课程作业 · 高校课堂交付** · 「基于大模型 API 构建具有实际应用价值的 AI Agent」
> **作品名**：云元 —— Self-Evolving Teaching System（沉浸式 AI 智能伴学系统）
> **GitHub**：[https://github.com/LittleXiaYuan/yunmeng-study-edu](https://github.com/LittleXiaYuan/yunmeng-study-edu)
> **定位**：聚焦「教学辅助 / 代码审查 / 个性化学习」三大教育场景的 AI Agent 实战

---

## 一、项目简介

本项目构建了一个**数据驱动 + 人机协同**的教学闭环系统：

- 默认场景：大学本科《数据库原理》课程（关系模型、SQL 查询、规范化、事务 ACID）
- 核心创新：**信任分门控**（Trust-gated disclosure）、**多 Agent 闭环**（Teacher / Tutor / Evaluator / Reflector / **CodeReview**）、**教师智能导入**、**学生教练「看见屏幕」**
- 工程亮点：Go 1.25 + Next.js 16 + React 19 + Tailwind v4 + React Bits；SQLite / JSON 双驱动存储；**所有 AI Agent 具备 LLM + 本地启发式双路径**，LLM 不可用系统不宕机
- 部署形态：单 exe 桌面版（双击即用）/ Docker Compose / Web 三种

## 六、关键创新点（详见 03-需求文档）

1. **信任分门控**（Trust-Gated Disclosure）：把"该不该给学生多深帮助"做成可量化的状态机（locked → hint → partial → explain），从机制上遏制"伸手要答案"。
2. **多 Agent 教学闭环**：Teacher（解析）/ Tutor（苏格拉底引导）/ Evaluator（评估）/ Reflector（班级反思）/ **CodeReview（代码审查）** — 5 个 Agent 都有 LLM + 本地启发式双路径，**LLM 不可用时系统仍可运行**。
3. **学生教练「看见屏幕」**：通过 `page_context` 机制让教练能"看见"学生当前做题的题干/阶段/草稿，引导不空泛。
4. **教师智能导入**：对话区直接挂 zip/docx/pdf/名单文件；Agent 识别意图（教案/练习/名单/噪声），自动入库或跳过；名单 txt 一键批量建号。
5. **可扩展代码审查 Agent**：SQL 走 SQLite 沙盒执行 + 风格/反模式检查；Python 走静态启发式（**不执行**，避免安全风险）；LLM 增强时强制"指出问题 + 方向性提示，**不直接给修正后代码**"，与 TutorAgent 的苏格拉底原则一脉相承。

## 七、风险与边界（**主动声明**）

- **数据规模**：SQLite + JSON 适合教学场景（小班 ≤ 200 学生）；大规模 SaaS 需切到 Postgres（schema 已就绪，未启用）
- **LLM 依赖**：每个 Agent 都有本地启发式 fallback，LLM 关闭后核心流程仍可演示；但**少部分功能（如 LLM 增强的代码审查）** 会降级为纯启发式
- **代码审查安全**：Python reviewer **不实际执行用户代码**（防沙箱逃逸）；SQL reviewer 走 `:memory:` SQLite + 事务 ROLLBACK，**不污染平台数据**
- **教学 vs 商业边界**：本系统是"教学机制 + 启发式兜底"，不是"AI 套壳"；大模型可插拔是核心设计原则
