## 0:30–3:00 场景 1：教学辅助（90s）

**主菜**：让评委亲眼看见"教练不给答案"这件事。

| 时间 | 画面 | 旁白 |
|------|------|------|
| 0:30–0:50 | 练习台全景：三阶段步骤轨、居中题卡、**左侧教练面板**亮着"在旁边看你写" | "这是学生的练习台。题目分阶段推进，左边始终坐着一位教练。注意——它现在什么都没说，它在等。" |
| 0:50–1:15 | 学生点「问教练」，弹层顶部出现**「正在看你的屏幕」**：题干、阶段、草稿摘要一并高亮 | "学生开口求助。教练做的第一件事不是回答——而是看。看他在做哪道题、写到了哪一步、草稿里已经有什么。" |
| 1:15–1:35 | 教练回复**逐字流式蹦出**（真实流式），最后落在一个反问上；角落信任分显示 20 · **locked** | "回复是一个字一个字『想』出来的。但看内容——它没给答案，只还给学生一个问题。因为此刻信任分只有 20，等级 locked：这个学生还没证明过自己在思考。" |
| 1:35–2:00 | 学生认真写完提交。**左栏批改过程逐条打勾**：读取答案 → 对照阶段要求 → 逐条核对 → 写反馈与评分 | "提交之后，教练的工作过程是全程可见的：它在读、在对照、在核对——不是一个转圈的黑盒。" |
| 2:00–2:20 | 反馈卡落下「已通过」，信任分跳动 **20 → 45**，轻撒花；左栏时间线多出一条记录 | "答得扎实，信任分立刻涨给你看。每一次反馈都会留在左边的时间线里——这个学生的思考轨迹，正在被记录。" |
| 2:20–2:45 | 快切：信任等级 locked / hint / partial / explain 四级示意；hint 级教练给出脚手架提示（仍不写完整答案） | "信任越高，教练愿意透露得越多：从只反问，到给提示，到给部分思路。**答案的深度，是学生自己挣来的。**" |
| 2:45–3:00 | 信任分 45 → 65 → 80 几次提升后，教练给出部分示例代码（partial 阶段），仍不写完整答案 | "到 partial 阶段，教练可以给一段示例——但完整答案要等学生自己挣到 explain。这一节是教学辅助的核心：教练不替你思考，只陪你思考。" |

> 拍摄提示：必拍"流式逐字输出"（本身就是演出效果，别剪快进）；左栏批改四步打勾动画；信任分 +N 跳动与撒花。**信任分剧情需要两个状态：先用低信任账号拍 locked 反问，再用答题后的状态拍 hint 提示**。

## 拍摄清单（对着现在的 UI）

- **必拍**：
  - 教练流式逐字输出（本身就是演出效果，别剪快进）
  - 左栏批改四步打勾动画
  - 信任分 +N 跳动与撒花
  - 「正在看你的屏幕」高亮卡
  - **SQL 沙盒执行报错**（带 code review 报告卡）
  - **LLM 关闭后仍能审查**（在 LLM 配置面板 toggle off）
  - **`go test` 输出全绿**
  - **`harmony-smoke.ps1` 输出 PASS**
  - **单 exe 双击启动**（画面切到桌面）

- **学生端**：用宽屏窗口录（≥ 1280px 才显示左侧教练面板）。
- **演示账号**：录前跑 `.\scripts\reset-university-seed.ps1`，避免旧记录穿帮。
- **信任分剧情**：两个状态——先用低信任账号拍 locked 反问，再用答题后的状态拍 hint 提示。

## 旁白三条铁律

1. **先让画面动，再开口解释**（避免"先说后做"违和感）
2. **一段只讲一件事**（别在 5 秒内塞 3 个卖点）
3. **金句（加粗处）前后各留半秒气口**（让评委有时间消化）

## 后期 / 转码

- 输出：H.264 MP4，1920×1080，30 fps，码率 8 Mbps
- 字幕：硬字幕（"中字"，黑底白字 + 大标题加粗）
- BGM：可选；选纯器乐（不喧宾夺主）
- 时长严格 ≤ 10:00；超时按 0:30 步长从场景 1/3 优先裁剪
