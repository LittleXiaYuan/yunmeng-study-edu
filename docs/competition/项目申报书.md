## 二、项目概况

### 2.1 项目背景与问题定义

在高校《数据库原理》课程教学中，存在三大核心痛点：

1. **学生认知差异大**：同一课堂中学生的理解程度参差不齐，教师难以实现个性化指导。
2. **教学反馈滞后**：传统作业批改周期长，教师无法及时发现学生的理解偏差和思维误区。
3. **深度学习不足**：学生习惯性"要答案"，缺少解释、反思、举例等高阶认知训练。

### 2.2 解决方案

本项目构建了一个**数据驱动的人机协同教学闭环系统**，核心创新在于：

- **四大 AI Agent 协作**：TeacherAgent（教案解析）、TutorAgent（苏格拉底式辅导）、EvaluatorAgent（多维评估）、ReflectorAgent（教学反思），形成"教→学→评→反思"完整闭环。
- **信任分机制（Trust Score）**：根据学生的提问质量、解释能力和反思深度动态计算信任分，按分数等级（locked / hint / partial / explain）差异化控制 AI 回答策略——不直接给答案，逐步引导学生自主思考。
- **RAG 教案检索**：基于教案库的检索增强生成，让 AI 辅导基于课程实际内容回答，而非泛泛而谈。
- **学生画像持久化**：记录每位学生的知识薄弱点、常见错误、思维风格，实现跨会话的个性化辅导。

## 四、技术创新点

### 4.1 信任分驱动的差异化教学

传统 AI 辅导系统是"问什么答什么"的单一模式。本系统首创 **Trust Score 信任分机制**：

```
信任分 = 提问质量(45%) + 解释能力(35%) + 思维深度(20%)
```

| 信任等级 | 分值范围 | AI 策略 |
|----------|----------|---------|
| locked | 0–29 | 只追问，不给任何提示 |
| hint | 30–59 | 允许提供方向性提示 |
| partial | 60–79 | 允许提供部分答案 |
| explain | 80–100 | 允许提供完整解释与迁移任务 |

学生必须通过自主思考提升信任分，才能获得更多 AI 帮助。这模拟了真实教学中"先证明你理解了，老师才会帮你更多"的教育逻辑。

### 4.2 多 Agent 教学闭环

系统采用四个专门化 AI Agent 协作，而非单一大模型直接回答：

1. **TeacherAgent**：教案知识图谱提取
2. **TutorAgent**：元认知学习教练（只提问，不回答）
3. **EvaluatorAgent**：多维度学习评估（7 个评估维度）
4. **ReflectorAgent**：教学反思与策略优化

每个 Agent 均有 **LLM + 本地 Fallback** 双路径，确保 LLM 服务不可用时系统仍可正常运行。

### 4.3 RAG 增强的课程适配

AI 辅导不是基于通用知识，而是通过 **检索增强生成（RAG）** 机制，自动检索教案库中与学生问题最相关的课程资料，使 AI 回答精准适配当前课程教学内容。

### 4.4 分步作业与过程性评价

区别于传统"题目→答案"模式，系统将作业拆分为三个认知阶段：

1. **先说想法**：用自己的话解释核心概念
2. **再举例子**：结合熟悉场景举例说明
3. **最后检查**：主动指出学习中容易出错的地方

每个阶段独立评估，学生必须通过当前阶段才能进入下一阶段。

## 五、数据要素应用

### 5.1 教学数据的采集与流转

| 数据要素 | 来源 | 用途 |
|----------|------|------|
| 教案知识图谱 | 教师上传的教案 | TeacherAgent 提取，RAG 检索匹配 |
| 学生画像数据 | 每次交互的评估结果 | 跨会话个性化辅导 |
| 信任分时序数据 | 每次作业/问答评估 | 学生成长轨迹可视化 |
| 多维评估数据 | EvaluatorAgent 评分 | 精准识别知识薄弱点 |
| 班级聚合数据 | ReflectorAgent 分析 | 教学策略优化依据 |
| 审计日志 | 全系统操作记录 | 教学过程可追溯 |

### 5.2 数据驱动的教学变革

- **从经验教学到数据教学**：教师不再凭感觉判断学生掌握情况，而是基于多维评估数据做出精准教学决策。
- **从统一教学到差异教学**：信任分机制让每个学生获得与其认知水平匹配的 AI 辅导策略。
- **从结果评价到过程评价**：分步作业记录学生完整的思考过程，而非仅评判最终答案。
- **从人工反馈到即时反馈**：AI Agent 即时评估学生答案并生成引导性反馈，消除教学反馈时延。

## 六、教育应用价值

### 6.1 对教师的价值

- **教案智能化**：一键提取知识点、难点和学习路径，减少备课工作量
- **精准教学**：基于班级数据分析结果调整教学重点
- **质量监控**：通过审计日志和学习会话追踪教学质量

### 6.2 对学生的价值

- **深度学习**：苏格拉底式追问强制学生思考，避免"伸手要答案"
- **个性化辅导**：AI 根据每位学生的知识画像提供定制化引导
- **即时反馈**：提交作业即刻获得评估和引导，不需等待教师批改

### 6.3 对教学管理的价值

- **数据可视化**：Dashboard 集中展示全班学习状况
- **过程可追溯**：完整的审计日志和学习会话记录
- **可复制推广**：Docker 一键部署，可快速推广到其他课程
