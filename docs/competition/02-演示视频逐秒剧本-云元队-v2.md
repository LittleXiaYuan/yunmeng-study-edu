# 02-演示视频逐秒剧本 v2（故事版）

时长：5:00 以内
主线：跟拍一个卡住的学生，让评委先看见"AI 不给答案"这件事，再看老师和超管怎么被串起来。
旁白基调：像在讲一个真实发生的下午，不是在念产品手册。语速放慢，留白比说满更重要。

---

| 时间 | 画面 | 旁白 |
|------|------|------|
| 0:00–0:12 | 学生端练习台特写：题目「关系模式转换」，输入框里打了半句话又删掉。光标闪烁，停顿两秒 | 一个学生卡住的时候，AI 能做的最省事的事，就是把答案递过去。我们见得够多了。 |
| 0:12–0:20 | 黑屏文字卡：**云元 · 沉浸式AI伴学系统**（鸿蒙赛道 · Agent 创新） | 云元想试试另一条路——做一个会等你想明白的教练。 |

## 0:20–1:55 学生端（95s）——主菜：不给答案的教练

| 时间 | 画面 | 旁白 |
|------|------|------|
| 0:20–0:35 | 练习台全景：三阶段步骤轨、居中题卡；**左侧教练面板**亮着"在旁边看你写" | 这是学生的练习台。题目分阶段推进，左边始终坐着一位教练——注意，它现在什么都没说，它在等。 |
| 0:35–0:55 | 学生点「问教练」，弹层顶部出现**「正在看你的屏幕」**：题干、阶段、草稿摘要一并高亮 | 学生开口求助，教练第一件事不是回答，而是看——看他正在做哪道题、写到了哪一步、草稿里已经有什么。 |
| 0:55–1:10 | 教练回复**逐字流式蹦出**，最后落在一个反问上；角落信任分显示 20 · locked | 回复是一个字一个字"想"出来的。但看内容——它没给答案，只还给学生一个问题。因为此刻信任分只有 20，等级 locked：这个学生还没证明过自己在思考。 |
| 1:10–1:30 | 学生认真写完提交。**左栏批改过程逐条打勾**：读取你的答案 → 对照阶段要求 → 逐条核对关键点 → 写反馈与评分 | 提交之后，教练的工作过程是全程可见的：它在读、在对照、在核对——不是一个转圈的黑盒。 |
| 1:30–1:45 | 反馈卡落下：「已通过」，信任分跳动 **20 → 45**，轻撒花；左栏时间线多出一条记录 | 答得扎实，信任分立刻涨给你看。每一次反馈都会留在左边的时间线里——这个学生的思考轨迹，正在被记录。 |
| 1:45–1:55 | 快切：信任等级 locked / hint / partial / explain 四级示意；hint 级教练给出脚手架提示（仍不写完整答案） | 信任越高，教练愿意透露得越多：从只反问，到给提示，到给部分思路。**答案的深度，是学生自己挣来的。** |

## 1:55–3:15 教师端（80s）——上午上传的教案，下午就被学生引用

| 时间 | 画面 | 旁白 |
|------|------|------|
| 1:55–2:15 | 切教师端，对话式工作台。把一个 zip 拖进对话（里面混着教案 docx、花名册 xlsx） | 老师这边没有复杂的后台，就是一个对话框。把一学期的资料原样扔进来，混着花名册也没关系。 |
| 2:15–2:35 | 导入报告卡展开：教案入库 ✓、抽取出概念标签、**花名册被识别为噪声自动跳过** | 系统自己分拣：教案入知识库、概念被抽出来做检索标记，花名册这种"噪声"被礼貌地跳过，并明确告诉你跳过了什么。 |
| 2:35–2:55 | 回学生端：提问后教练回复下方出现引用卡**《关系模型与 SQL 查询基础》** | 关键在这里——上午老师上传的教案，下午就出现在学生追问的引用里。教与学之间，第一次有了一条看得见的通路。 |
| 2:55–3:15 | 教师端班级报告：共性错误 TOP、**全班信任分分布**、教学建议 | 老师最后拿到的不是一张平均分，而是全班的"思考状态"：谁在真想，谁在套模板，共性卡点在哪一步。 |

> 拍摄提示：批量导入名单（created/failed 明细）如果时间紧可以剪成 2 秒快闪塞在 2:35 前，不单独讲。

## 录制清单（对着现在的 UI）

- **必拍**：教练流式逐字输出（本身就是演出效果，别剪快进）；左栏批改四步打勾动画；信任分 +N 跳动与撒花；「正在看你的屏幕」高亮卡。
- 学生端用宽屏窗口录（≥1280px 才显示左侧教练面板）。
- 演示账号走干净数据：录前跑 `.\scripts\reset-university-seed.ps1`，避免旧记录穿帮。
- 信任分剧情需要两个状态：先用低信任账号拍 locked 反问，再用答题后的状态拍 hint 提示。
- 旁白三条铁律：先让画面动，再开口解释；一段只讲一件事；金句（加粗处）前后各留半秒气口。
