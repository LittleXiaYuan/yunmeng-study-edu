云元——沉浸式AI伴学系统
赛道：鸿蒙赛道 · 作品方向：Agent 创新

============================================================
一、重要说明（评审请先看）
============================================================
1. 本压缩包为「伴学 Agent 策略引擎 + 可运行演示系统」源代码/演示包。
2. 本作品方向为 Agent 创新，演示物为源代码/演示系统，而非 HarmonyOS 应用 HAP。
3. 鸿蒙侧触达规划：小艺开放平台 Agent / Skills 作为用户入口与主动服务触点，
   复用本系统的信任分门控、多 Agent 闭环与课程知识库能力。
4. 初赛阶段完整伴学闭环与教师智能导入已在本演示系统中可运行验证。

============================================================
二、快速运行（Windows）
============================================================
方式 A · 开发模式
  1) 后端：
     cd backend
     go run .\cmd\edu-server
     默认 http://127.0.0.1:18080
  2) 前端（另开终端）：
     cd teacher-web-next
     npm install
     npm run dev
     浏览器打开 http://localhost:3000

方式 B · 桌面演示包（若包含 dist-desktop）
  双击 StudyAI教学系统.exe
  浏览器访问 http://127.0.0.1:18080

四、建议演示路径（对应视频）
============================================================
  1) 教师登录 → 导入资料（zip/docx/pdf 或粘贴文本）
     - Agent 识别教案/练习/噪声，展示导入报告
  2) 知识库引用试跑 → 检索刚导入知识点
  3) 学生登录 → 提问要答案 → 观察只引导与信任策略
  4) 作业/评价或教师侧学情（可选）
