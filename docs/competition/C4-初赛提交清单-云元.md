### 作品简介（≤800 字，约 750 字）

```text
【作品名称】云元——沉浸式AI伴学系统

【创意背景】
高校课程学习中，学生基础差异大、教师难以及时个性化指导；通用大模型又容易变成“答案机”，削弱思考过程。云元面向《数据库原理》等真实课程，打造鸿蒙生态下的沉浸式伴学 Agent：在合适的时机、以合适的深度陪伴学生完成理解、举例与反思，并帮助教师把零散资料变成可检索的课程知识库。

【核心创意与功能】
1. 信任分门控：综合提问质量、解释与反思深度，将辅导权限分为只提问、可提示、可部分作答、可完整讲解四级。低信任时 Agent 只引导不泄题，信任提升后再逐步开放讲解。
2. 多 Agent 教学闭环：Teacher 解析教案，Tutor 苏格拉底式辅导，Evaluator 多维评价，Reflector 汇总共性与教学建议，形成教—学—评—思闭环。
3. 教师侧智能导入：对话区直接挂 zip/docx/pdf/名单文件；Agent 识别意图，区分教案、练习与噪声（如花名册），只把有用材料写入知识库并解析概念，在对话内给出导入报告；名单类文件可一键批量建号。
4. 学生教练「看见屏幕」：教练能读取学生当前题干、阶段与草稿，据此引导而非空泛提问；回答可带课程资料引用。
5. 组织与隔离：学校-班级-课程-用户层级管理（超管后台），教师/学生数据按班级严格隔离。
6. 鸿蒙触达：以对话为主要自然交互；通过小艺 Agent/Skills 作为入口与主动服务触点（作业临期、反复错题等节点主动介入），复用同一套伴学策略。

【实现路径】
伴学策略与教学业务由可运行服务承载（多角色、作业流、会话与学情），大模型经兼容接口调用并具备本地降级。鸿蒙侧以 Agent 为用户入口，后端复用云元信任策略与知识库。初赛已具备完整闭环与智能导入演示；复赛交付可运行小艺测试态 Agent 并强化主动服务。

【应用前景】
可复制到多门课程与班级教学，减轻重复答疑，强化高阶思维训练，具备清晰教育场景与落地路径。
```
