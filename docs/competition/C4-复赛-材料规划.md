## 七、小艺 Agent 上线前步骤（9 月前完成，需人工衔接）

以下是关键路径，需要华为账号 + 小艺开放平台操作，不能由代码直接代替：

1. **部署后端到公网**
   - 方法见 `docs/DEPLOYMENT.md` / `docs/SQLITE_DEPLOYMENT.md`
   - 需提供 HTTPS 域名；本地测试可用 ngrok/expose 临时隧道替代

2. **小艺开放平台建 Agent「云元伴学」**
   - 登录华为开发者联盟 → 小艺开放平台
   - 新建 Agent，填入人设/系统提示词与开场白（可与 `harmony/xiaoyi/README.md` 保持一致）
   - 配置「技能」：`yunYuanTutorChat`（后端接口地址、鉴权 token、请求/响应 schema）

3. **测试态录制与二次剪辑**
   - 使用 `scripts/harmony-smoke.ps1` 跑一遍端到端，确保返回无误导视频
   - 将系统提示词、主动服务场景、信任等级变化剪入 `02-演示视频` 对应段落（4:20–5:00）

4. **上架（可选）**
   - 若申请上架，依据小艺开放平台要求提交审核；审核周期 5–7 个工作日出结果

## 三、02 演示视频分镜（≤5 分钟）

| 时间 | 画面 | 要点 |
|------|------|------|
| 0:00–0:15 | 标题卡 | 云元 · 鸿蒙赛道 Agent 创新 |
| 0:15–1:05 | 教师：对话区 📎 挂 zip+名单 txt | 一句「帮我导入这些资料，再批量导入学生名单」 |
| 1:05–1:35 | 导入报告卡 + 知识库引用试跑 | 教案入库、名单噪声被过滤、概念可检索 |

| 2:05–3:20 | 学生：作业台打开教练 | 👁「正在看你的屏幕」+ 题干草稿被点名 + 只引导不泄题 |
| 3:20–3:50 | 信任分变化前后对比 | locked 只提问 → 提升后给提示 |
| 3:50–4:20 | 教师班级报告 / 超管学校管理一闪 | 平台完整度 |
| 4:20–5:00 | 鸿蒙入口：小艺 Agent 对话（或冒烟脚本+规划页） | 同一套伴学策略在鸿蒙侧可用 |
