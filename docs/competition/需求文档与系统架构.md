# 需求文档与系统架构

## Self-Evolving Teaching System

---

## 一、功能需求

### 1.1 教师端功能

| 编号 | 功能 | 用户故事 | 优先级 |
|------|------|---------|--------|
| T-01 | 教案上传 | 教师上传 TXT/MD/ZIP 文件，系统自动解析知识点 | P0 |
| T-02 | 知识图谱查看 | 教师查看教案解析出的 concepts / difficulties / learning_path | P0 |
| T-03 | AI 助教对话 | 教师与 AI 对话，生成教学建议或写入教案库 | P1 |
| T-04 | 分步作业创建 | 教师手动创建或 AI 自动生成三阶段分步作业 | P0 |
| T-05 | 班级管理 | 创建班级、添加学生、关联课程 | P0 |
| T-06 | 课程管理 | 创建/编辑课程，绑定到班级 | P0 |
| T-07 | 教学分析报告 | 查看班级/学生学习报告，含共性问题和策略建议 | P1 |
| T-08 | LLM 配置 | 在线配置 LLM 的 BaseURL / APIKey / Model，运行时生效 | P1 |
| T-09 | 学习会话查看 | 查看学生的历史学习会话和评估数据 | P2 |
| T-10 | 作业尝试管理 | 查看学生作业提交记录，支持重置 | P2 |

### 1.2 学生端功能

| 编号 | 功能 | 用户故事 | 优先级 |
|------|------|---------|--------|
| S-01 | 分步作业提交 | 学生逐步提交作业答案，每步获得引导性反馈 | P0 |
| S-02 | 信任分查看 | 学生查看自己的信任分等级和变化趋势 | P1 |
| S-03 | 辅导问答 | 学生就课程内容提问，获得苏格拉底式引导 | P1 |
| S-04 | 学习进度 | 学生查看已完成的作业和学习会话 | P2 |

### 1.3 管理员功能

| 编号 | 功能 | 用户故事 | 优先级 |
|------|------|---------|--------|
| A-01 | 用户管理 | 创建/编辑/启停用户账号，分配角色 | P0 |
| A-02 | 全局 Dashboard | 查看全系统概览数据 | P1 |
| A-03 | 审计日志 | 查看全系统操作审计记录 | P1 |

---

## 二、非功能需求

| 类别 | 需求 | 实现方式 |
|------|------|---------|
| 高可用 | LLM 不可用时系统不宕机 | 每个 Agent 有本地 Fallback |
| 安全性 | 密码不明文存储 | bcrypt 哈希存储 |
| 安全性 | 数据脱敏 | sanitize 层统一清除敏感字段 |
| 安全性 | CORS 白名单 | 只允许指定前端地址跨域 |
| 可配置 | 存储引擎可切换 | 环境变量 EDU_STORAGE_DRIVER |
| 可部署 | 一键部署 | Docker Compose 容器化 |
| 可扩展 | API 设计统一 | RESTful + 分页 + 角色鉴权 |

### 3.2 数据流图：学生分步作业

```
学生提交答案
      │
      ▼
  SubmitHomework()
      │
      ├─ 权限校验（student 角色 + 班级匹配）
      │
      ├─ 获取 HomeworkTask + HomeworkStep
      │
      ├─ EvaluatorAgent 评估答案
      │   ├─ LLM 评分（7 个维度）
      │   └─ Fallback: 启发式评分
      │
      ├─ 更新学生画像（StudentMemory）
      │   ├─ understanding_score
      │   ├─ reflection_level
      │   ├─ trust_score
      │   ├─ common_errors
      │   └─ thinking_style
      │
      ├─ 计算信任分 → 确定 TrustPolicy
      │   ├─ locked:  只追问
      │   ├─ hint:    给提示
      │   ├─ partial: 给部分答案
      │   └─ explain: 给完整解释
      │
      ├─ 判断是否通过当前阶段
      │   ├─ 通过 → 进入下一阶段
      │   └─ 未通过 → 重做当前阶段
      │
      ├─ 生成引导性反馈（LLM 或模板）
      │
      ├─ 持久化 HomeworkAttempt
      │
      └─ 返回 GuidedHomeworkResponse
            ├─ homework:  作业信息
            ├─ attempt:   本次尝试记录
            ├─ trust:     当前信任策略
            ├─ next_step: 下一阶段（如有）
            ├─ message:   引导反馈文本
            └─ memory:    更新后的学生画像
```

### 3.3 数据流图：教案上传与 RAG

```
教师上传教案文件
      │
      ▼
  POST /edu/lessons/upload
      │
      ├─ 解析文件（TXT / MD / ZIP）
      │   └─ ImportLessonBundle()
      │
      ├─ TeacherAgent 解析知识图谱
      │   ├─ LLM: 提取 concepts / difficulties / learning_path
      │   └─ Fallback: 正则提取关键术语
      │
      ├─ 持久化 Lesson (含 analysis)
      │
      └─ 进入 RAG 索引
            │
            ▼
       后续学生提问时
            │
            ├─ 关键词提取
            ├─ 教案库检索（标题+内容+概念匹配）
            ├─ 按相关度评分排序
            └─ Top-K 结果注入 TutorAgent 上下文
```
