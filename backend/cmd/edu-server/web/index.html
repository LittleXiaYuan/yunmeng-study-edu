核心能力

云雀教学 Agent 建立在三项核心能力之上。

三者环环相扣，把「因材施教」从一句口号变成每一次对话里都在发生的事。

01 — 信任分

动态解锁式辅导

帮助并非无条件给出，而是随学生展示出的理解程度分级解锁：从只提问，到给提示、给线索，直到完整讲解。

02 — 检索

RAG 为引导提供依据

教案上传后即进入基于关键词的检索索引，TutorAgent 的每一次提问都能追溯到具体的教材出处，而非凭空生成。

03 — 反思

元认知训练

提问式引导迫使学生复盘自己的思路，系统记录反思等级与思维风格，让「学会学习」本身可被追踪、可被量化。

适用场景

一套教学闭环，服务学生、教师与院校三方。

同一套信任分与四 Agent 机制，在不同角色的视角里呈现出不同的价值。
