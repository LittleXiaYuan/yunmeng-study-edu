# 云元 · 鸿蒙接入说明

> 作品：云元——沉浸式AI伴学系统
> 赛道：2026 中国高校计算机大赛—人工智能创意赛 · 鸿蒙赛道 · **Agent 创新**

本目录给出云元伴学 Agent 在鸿蒙生态的两条接入路径。
当前可运行验证的是「云元后端 + Web 演示」（含信任分门控、四 Agent 闭环、智能导入）；
复赛交付物为「小艺开放平台测试态 Agent」，HAP 轻壳作为补充入口。

---

## 路径 A：小艺开放平台 Agent / Skills（复赛主交付）

1. 登录小艺开放平台，创建 Agent「云元伴学」。
2. 用 [`xiaoyi/openapi.yaml`](./xiaoyi/openapi.yaml) 注册两个技能：
   - `yunYuanTutorChat`：伴学对话（苏格拉底引导，不直接给答案）
   - `yunYuanTrustPolicy`：查询学生当前信任分等级
3. Agent 人设（可直接粘贴）：

```text
你是「云元」苏格拉底伴学教练，服务大学《数据库原理》课程。
规则：
1. 绝不直接给最终答案；先肯定学生已想对的部分，再用一个引导性问题收尾。
2. 学生信任分低时只提问；信任分提升后才逐步给提示。
3. 回答尽量短，像真人助教；每次回复都以问号结尾。
4. 学生作业卡壳时，引导他先说「题目在问什么、卡在哪、能想到的例子」。
```

4. 开场白建议：`我是云元伴学教练。卡在哪一步了？说给我听，我陪你一起想，但不会直接告诉你答案哦。`
5. 联调：技能后端地址指向已部署的云元服务（本地 `http://127.0.0.1:18080`，公网部署后换成域名），鉴权用预配置的学生账号 token（见 openapi.yaml 的 security 说明）。

## 路径 B：HAP 轻壳（补充入口）

[`arkts/Index.ets`](./arkts/Index.ets) 是 ArkUI 页面骨架：
- Web 容器加载云元学生端页面（部署后的 HTTPS 地址）
- 注释内附 `ohos.net.http` 原生调用 `/edu/chat` 的示例（可做原生对话页）

> 该骨架需 DevEco Studio 打开编译验证；本仓库不内置鸿蒙工程构建。

## 本地冒烟验证（无需鸿蒙设备）

```powershell
# 1. 启动后端
cd backend; go run .\cmd\edu-server

# 2. 另开终端，模拟鸿蒙入口触发伴学对话
powershell -File scripts\harmony-smoke.ps1
# 期望输出：HARMONY SMOKE PASS
```

冒烟脚本做的事 = 鸿蒙入口要做的事：登录学生账号 → 带 `page_context` 调 `/edu/chat` →
断言回复是引导性提问且带信任等级。脚本通过即代表「鸿蒙侧入口可触发伴学对话」。

## 信任分门控（差异化卖点，演示必讲）

| 信任分 | 等级 | Agent 行为 |
|--------|------|------------|
| <30 | locked | 只提问，不给任何提示 |
| 30–59 | hint | 允许给提示 |
| 60–79 | partial | 允许给部分答案 |
| ≥80 | explain | 允许完整解释 |

鸿蒙侧小艺 Agent 复用同一套策略——学生在小艺里也要「先证明自己理解了，才解锁更多帮助」。
